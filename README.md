# StayDesk — Production-Grade PG & Hostel Management Platform

A modern, full-stack, production-grade PG (Paying Guest) and Hostel management application built with **React**, **TypeScript**, **Tailwind CSS**, **Node.js Express**, **Native SQLite (`node:sqlite`)**, **JWT Authentication**, and **Capacitor Mobile Support**.

---

## Architecture Overview

StayDesk has been completely modernized from a static prototype to a production-grade architecture:

```
├── client (src/)
│   ├── components/         # Reusable UI components & modals (ReceiptModal, RoomModal, TenantModal, etc.)
│   ├── context/            # Global Auth & Multi-Property Context
│   ├── pages/
│   │   ├── Login.tsx       # Auth screen with 1-click role switcher & credentials form
│   │   ├── owner/          # PG Owner Management Suite (Dashboard, Rooms, Tenants, Rent, Reminders, Expenses, Complaints, Notices, Backup)
│   │   ├── tenant/         # Resident Tenant Portal (My Stay, Rent status, Roommate directory with privacy consent, Receipts, Maintenance)
│   │   └── superadmin/     # Super Admin Platform Console (Properties, Admins, Ecosystem metrics, Security audit logs)
│   ├── services/api.ts     # Type-safe API client with JWT Bearer auth
│   └── types.ts            # Domain TypeScript models
├── server/
│   ├── db.ts               # Relational SQLite database (`node:sqlite`), automated migration & foreign key constraints
│   ├── auth.ts             # Password hashing (bcryptjs), JWT token signing & role enforcement middleware
│   ├── seed.ts             # Production seed dataset (Properties, Rooms, Beds, Tenants, Payments, Expenses)
│   └── index.ts            # Express REST API endpoints & static production file serving
├── dist/                   # Production-optimized web bundle generated by Vite
└── android/                # Native Android application synced via Capacitor
```

## Production Security & Capabilities

1. **Role-Based Access Control (RBAC)**:
   - **Super Admin**: Platform-wide metrics, manage and create properties, assign PG owners, audit log stream.
   - **PG Owner / Admin**: Multi-property switcher (`property_id` isolation), occupancy analytics, visual room & bed matrix, tenant check-in/check-out with bed freeing, monthly rent billing ledger, partial payments, instant PDF/printable receipts, WhatsApp rent reminders, expense tracking, net cash flow, maintenance tickets, and announcements.
   - **Resident Tenant**: Personal stay summary, monthly rent status, simulated UPI QR code payment, privacy-protected roommate view (phone number strictly hidden unless sharing consent is recorded), payment ledger with receipt reprint, maintenance ticket submission, PG notices.

2. **Multi-Property Isolation**:
   - Single admin account can manage multiple PG branches (e.g. *Main Street PG* and *Katpadi Residency*).
   - Every database query strictly validates the owner's assigned properties.

3. **Room & Bed Integrity**:
   - Dynamic bed capacity validation prevents over-allocation and duplicate bed assignments.
   - Checking out a tenant frees the bed for new allocation while retaining the full financial and stay ledger.

4. **Relational Database (`node:sqlite`)**:
   - Fully ACID-compliant SQLite storage with WAL (Write-Ahead Logging) mode and foreign keys enabled.
   - Stored on disk in `data/staydesk.db`.

## Development & Production Commands

### 1. Run Development Server (Concurrent API + Vite HMR)
```bash
npm run dev
```
- API Server runs at `http://localhost:5000`
- Vite Web Dev Server runs at `http://localhost:5173` (with `/api` proxy)

### 2. Build Production Bundle
```bash
npm run build
```
Compiles TypeScript and outputs the production bundle to `dist/`.

### 3. Run Production Server
```bash
npm start
```
Starts the Express server on port 5000, serving the REST API and the production web app from `dist/`.

### 4. Build and Run on Android (Capacitor)
```bash
npm run build
npm run sync:android
npm run open:android
```
Opens the project in Android Studio to build APK / AAB.
